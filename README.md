Minceraft v1.8

Minceraft v1.8 is a browser-based voxel sandbox game designed to capture the feel of classic Minecraft-style gameplay. Built with HTML, JavaScript, and Three.js, the game focuses on block-based exploration, building, survival mechanics, and procedural world generation in a fully playable 3D browser experience.

Players can explore a generated world made of blocks, gather resources, break and place terrain, manage inventory, craft useful items, and survive in a sandbox environment inspired by the "Golden Age" of Minecraft. The project includes core systems such as world generation, caves, multiple biomes, inventory and hotbar management, crafting, furnaces, storage blocks, tools, mobs, sound, and local save support.

The goal of the project was to recreate the charm and simplicity of classic sandbox survival gameplay while running directly in the browser. It is meant as a fan-made recreation and technical project that pays tribute to the style, atmosphere, and mechanics of older voxel games.

This project is not official and is not affiliated with, endorsed by, or connected to Mojang or Microsoft. It is simply a fan recreation inspired by classic Minecraft.
